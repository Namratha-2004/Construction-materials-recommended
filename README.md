# 🏗️ AI-Based Construction Material Recommendation System

## 📌 Project Overview

The **AI-Based Construction Material Recommendation System** is a machine-learning-based project designed to recommend suitable construction materials based on relevant project requirements and input parameters.

The system uses data preprocessing, feature engineering, and machine learning techniques to identify suitable material recommendations. A web-based interface was developed to make the recommendation system accessible to users.

> **Project Type:** Group Project
> **My Role:** Machine Learning & Data Processing
> **Team Size:** 4

---

## 🎯 Objective

The main objective of this project is to develop a data-driven recommendation system that can assist users in selecting suitable construction materials based on the given requirements.

The project focuses on applying machine learning to construction-related data and presenting the resulting recommendations through a web application.

## 📊 Model Evaluation

The model was evaluated on a held-out test set comprising 20% of the dataset (2,000 samples).

| Metric             | Score |
| ------------------ | ----: |
| Accuracy           | ~0.20 |
| Weighted Precision | ~0.19 |
| Weighted Recall    | ~0.20 |
| Weighted F1-score  | ~0.19 |

### Interpretation

The model achieved approximately 20% accuracy on the held-out test set. The results indicate that the current model has limitations in accurately distinguishing between the target classes.

These results provide a baseline for further improvement through better feature engineering, additional training data, algorithm comparison, and hyperparameter tuning.
